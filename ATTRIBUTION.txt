================================================================================
ADDED DURING BUILD — PHI redaction, auth, and test infrastructure
================================================================================

Microsoft Presidio (presidio-analyzer, presidio-anonymizer)
  Licence: MIT
  https://github.com/microsoft/presidio
  PHI detection and anonymisation. Used in ai-service/services/redaction.py with
  custom Singapore PatternRecognizers layered on top.

spaCy
  Licence: MIT
  https://github.com/explosion/spaCy
  NLP pipeline backing Presidio's NER.

en_core_web_sm (spaCy English model)
  Licence: MIT
  https://github.com/explosion/spacy-models
  Small English NER model. Supplies PERSON/LOCATION detection. Trained on US/EU
  news text, which is why custom recognisers handle Singapore naming
  conventions.

PyJWT
  Licence: MIT
  https://github.com/jpadilla/pyjwt
  Verifies Supabase JWTs on AI service endpoints (ES256 via JWK, or legacy
  HS256).

cryptography
  Licence: Apache-2.0 OR BSD-3-Clause
  https://github.com/pyca/cryptography
  ES256 public-key handling for JWT verification.

psycopg (psycopg3, with binary extras)
  Licence: LGPL-3.0-or-later
  https://github.com/psycopg/psycopg
  PostgreSQL driver. TEST INFRASTRUCTURE ONLY — used by the ephemeral-cluster
  harness in ai-service/tests/support/. Not a runtime dependency of any service.

PostgreSQL (initdb / pg_ctl / pg_isready client binaries)
  Licence: PostgreSQL Licence (permissive, BSD-like)
  https://www.postgresql.org/
  Required on PATH to run the test suite, which builds a throwaway cluster.

DATA
--------------------------------------------------------------------------------

All patient data in this repository is synthetic. Alice Wong, Robert Lee, and
both clinics are fabricated for demonstration. No real patient data, and no real
NRIC, phone number or medical record number, appears anywhere in this repository
or its test fixtures.
